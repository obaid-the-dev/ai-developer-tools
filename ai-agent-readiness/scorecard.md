# Workflow readiness scorecard

Score each 1 (low) – 5 (high). Start with the highest total; ties go to the more reversible workflow.

| Workflow | Volume | Clear "done" | Unstructured input | Reversible | Data/API access | Named owner | Total |
|---|---|---|---|---|---|---|---|
| Example: AP invoice intake | 5 | 5 | 5 | 4 | 3 | 5 | 27 |
|  |  |  |  |  |  |  |  |

Rules of thumb
- Unstructured input scores low (1)? → plain rule-based automation is probably cheaper.
- Reversible scores ≤ 2? → start with "draft for approval" only.
- No named owner? → don't start.
